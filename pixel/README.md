# 雾崎来信 · 像素探索版

双击 `index.html`。竖屏 320×480 逻辑像素，整数倍放大，不需要服务器。

## 操作

| 操作 | 键 | 触屏 |
|---|---|---|
| 走 | WASD / 方向键 | 点地面 |
| 跑 | Shift | — |
| 调查 | E / 空格 | 点物件，或走近后点「调查」 |
| 信袋 | Q | 底栏「信袋」 |
| 笔记 | R | 底栏「笔记」 |
| 地图 | M | 底栏「地图」 |
| 信外 / 信内 | F | 底栏「雾」 |
| 关窗 | Esc | 点弹窗外 |

## 规则

- 读完一个地方的信，那地方才能在信外 / 信内之间切。
- 左上角「下一步」写着当前该去哪；没看过的地方一律冒「！」，走近才出虚线框。
- 澪、薇拉、纱夜、归途在场景里有小人；信箱、门垫、剪页这类线索点画了道具。
- 三张同类线索（邮戳 / 信纸 / 票根）合成一条规则，写进笔记。
- 三律抉择有 15 秒，三滴水滴完自动选「常理」；没有 Game Over。
- 回访三处只能进两处；终局四条路，取决于你带回了什么。

## 文件

```
index.html        页面骨架（HUD / 面板 / 弹窗 / 标题 / 结局）
css/style.css     所有尺寸按 --u 缩放（--u = 舞台宽 / 320）
js/content.js     六场景 × 双界、9 线索、3 规则、9 三律、4 结局、卡面
js/art.js         像素小人、图标、雾、雨、灰、热点标记、雾切换
js/game.js        引擎：移动、检视、线索、抉择、场景切换、存档、音
assets/bg/        12 张底图 + 标题（由 tools/pixel_build.py 生成）
assets/card/      卡面 / 头像 / 像素概念稿（由 tools/pixel_cards.py 生成）
assets/npc/       澪的像素小人（由 tools/pixel_npc.py 生成）
_debug/           带网格的底图，用来对热点坐标
```

## 改内容

- 场景、热点、台词、三律、结局：`js/content.js`
- 热点坐标对不上：看 `_debug/<场景>_grid.png`（网格 32px）
- 改完 `node tools/smoke.js` 跑一遍主线

调试参数：`?scene=street&form=in`、`?clues=1`、`?revisit=1`、`?fresh=1`
控制台：`__KIRIZAKI__`
